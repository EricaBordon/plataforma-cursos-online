# plataforma-cursos-online
Plataforma de cursos online tipo Udemy desarrollada con Django, PostgreSQL y Django REST Framework.
# Fundamento del Proyecto
El proyecto tiene como finalidad desarrollar una plataforma de cursos online inspirada en sistemas educativos digitales, permitiendo la gestión de cursos, usuarios e inscripciones dentro de un entorno virtual.
La aplicación será desarrollada con Django y PostgreSQL, utilizando una API REST y funcionalidades relacionadas con autenticación, gestión de contenidos y seguimiento del progreso de los estudiantes.
